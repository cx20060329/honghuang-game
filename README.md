# 洪荒神话 - 文字冒险游戏

一款基于洪荒神话背景的文字冒险游戏，从龙汉初劫到巫妖大战，体验洪荒世界的史诗之旅。

**提供两个版本：命令行版（Node.js）和网页版（纯HTML）**

## 游戏简介

**洪荒神话**是一款以中国神话为背景的文字冒险游戏。玩家将随机扮演15位洪荒大能之一（帝俊、东皇太一、老子、元始天尊、通天教主、鲲鹏、红云、冥河、西王母、常羲、女娲、后土、元凤、祖龙、麒麟老祖），经历从龙汉初劫到巫妖大战的史诗历程。

### 核心特性

- **15位可玩角色**：每位角色拥有独特的属性、背景故事和专属剧情
- **5大属性系统**：根脚、气运、道行、声望、心性
- **94个剧情节点**：覆盖龙汉初劫、道魔之战、紫霄宫讲道、巫妖崛起、巫妖决战五大阶段
- **多结局设计**：根据选择和属性触发不同结局
- **修炼系统**：主动悟道（高风险高收益）或闭关修炼（稳定收益）
- **成就系统**：12个成就等待解锁
- **历史干预**：可选择顺应历史或尝试改变命运
- **死亡机制**：气运或道行归零将导致陨落


## 操作指南

### 主菜单

| 选项 | 说明 |
|------|------|
| `[1]` | 开始新游戏（随机选择角色） |
| `[2]` | 读取存档 |
| `[3]` | 退出游戏 |

### 游戏内命令

| 命令 | 说明 |
|------|------|
| `[1-9]` | 选择对应选项 |
| `[W]` | 打开修炼菜单（悟道/闭关） |
| `[C]` | 查看成就列表 |
| `[A]` | 查看当前属性 |
| `[I]` | 查看已获得物品 |
| `[S]` | 手动存档 |
| `[L]` | 读取存档 |
| `[Q]` | 退出游戏 |

### 修炼系统

| 选项 | 说明 | 风险 |
|------|------|------|
| `[1] 主动悟道` | 高收益，成功率基于根脚 | 失败可能损失道行 |
| `[2] 闭关修炼` | 稳定收益，无风险 | 收益较低 |

**冷却时间**：每次修炼后需要等待3个回合

### 属性说明

| 属性 | 说明 | 影响 |
|------|------|------|
| 根脚 | 先天根基 | 影响修炼成功率 |
| 气运 | 天命气数 | 归零则陨落 |
| 道行 | 修行境界 | 归零则陨落 |
| 声望 | 名望地位 | 影响部分剧情选项 |
| 心性 | 心境修养 | 影响部分剧情选项 |

### 死亡机制

- **气运归零**：天命已绝，存在被洪荒遗忘
- **道行归零**：元神消散，堕入轮回

死亡后可选择重新开始游戏。

## 技术实现

- **网页版**：纯 HTML + CSS + JavaScript，单文件，无依赖
- **命令行版**：Node.js + readline
- **数据**：JSON格式剧本数据
- **测试**：Jest单元测试框架
- **存档**：localStorage（网页）/ JSON文件（命令行）

## 数据验证

运行验证脚本检查数据完整性：

```bash
node validate_game_data.js
```

验证项：
- 节点ID唯一性
- 选项跳转目标存在性
- 孤立节点检测
- 角色属性范围
- 属性越界风险
